# 📌 Set Flow
{: .notice}

<span class="color-keyword">Edge Loop 선택 → RMB → Set Flow → Set Flow</span> 선택한 Edge를 주변 Geometry의 흐름에 맞춰 재배치

<span class="color-keyword">Edges 선택 → RMB → Set Flow → Set Linear</span> 연속적으로 연결된 Edge들을 하나의 직선 형태로 정렬 <span class="color-comment">끝과 끝이 연결된 폐쇄형 Edge Loop를 선택한 경우에는 Set Linear가 제대로 작동하지 않음(Closed Edge Loop)</span>
