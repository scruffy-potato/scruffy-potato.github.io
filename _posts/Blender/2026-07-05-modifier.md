# 📌 Modifier?
{: .notice}

원본 Mesh를 직접 수정하지 않고 다양한 효과나 변형을 유연하게 적용할 수 있는 기능

여러 개의 Modifier를 사용할 경우 상단에 있는 Modifier부터 우선 적용

Modifier는 Apply 하기 전까지 허상이며, Apply 할 경우 수정이 불가능하기 때문에 최종 완성이 되기 전까지는 하지 않는 게 좋음




# 📌 Origin?
{: .notice}

일부 Modifier는 Origin을 기준으로 계산, 이 때 Origin은 Modifier가 적용될 기준점이 된다

Empty 오브젝트를 만들어 필요한 곳에 위치시켜 Origin으로 사용할 수 있음




# 📌 Simple Deform
{: .notice}

Deform → Simple Deform

• <span class="color-keyword">Twist</span> : 비틀기

• <span class="color-keyword">Bend</span> : 구부리기

• <span class="color-keyword">Taper</span> : 한쪽으로 좁아지거나 넓어지기

• <span class="color-keyword">Stretch</span> : 늘리거나 압축하기




# 📌 Mirror
{: .notice}

Generate → Mirror

• <span class="color-keyword">Mirror</span> : 특정 축 기준으로 대칭 복사

• <span class="color-variable">Clipping</span> : 대칭되는 중심에서 Vertex가 겹쳐 붙어 중앙선이 찢어지는 걸 방지할 수 있음

• <span class="color-variable">Merge</span> : 대칭 복사된 Vertex가 일정거리(Merge Distance) 이내에 있을 경우 자동 병합됨
