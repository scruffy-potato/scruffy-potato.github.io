# 📌 Transform Orientations
{: .notice}

• <span class="color-keyword">Transform Orientations</span> : Grab, Rotation, Scale을 사용할 때 기준이 되는 좌표축을 정함

 ◦ <span class="color-variable">Global</span> : 블렌더 월드의 글로벌 좌표를 사용

 ◦ <span class="color-variable">Local</span> : 오브젝트의 로컬 좌표를 사용

 ◦ <span class="color-variable">Normal</span> : Face Normal 기준으로 사용, Grab 후 Z축을 선택할 경우 Face가 바라보는 Face Normal 방향이 됨
