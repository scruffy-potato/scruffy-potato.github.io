<span style="color:gray">blender version 5.2.0</span>




# 📌 에디트 모드에서 Mesh를 다른 오브젝트로 분리
{: .notice}

<span class="color-keyword">분리 할 Mesh 선택 → P → Selection</span>




# 📌 Vertex, Edge, Face
{: .notice}

<span class="color-keyword">1</span> Vertex

<span class="color-keyword">2</span> Edge

<span class="color-keyword">3</span> Face




# 📌 Vertex, Edge Dissolve
{: .notice}

<span class="color-keyword">Vertex, Edge 선택 → Ctrl + Delete</span> 선택한 Vertex, Edge를 주변 Mesh의 형태를 최대한 유지하면서 용해 <span class="color-comment">(Triangle, N-gon 을 Quad 로 만들 때 사용)</span>




# 📌 Reset to Default Value
{: .notice}

Extrude, Inset, Bevel 등 수정 패널에서 원하는 값에 우클릭 누를 시 Reset to Default Value로 기본 값으로 돌릴 수 있음




# 📌 Flip
{: .notice}

<span class="color-keyword">Face 선택 → Alt + N → Flip</span> 선택된 면 Flip <span class="color-comment">(빨간 면 정면으로 돌리기)</span>




# 📌 L-inked
{: .notice}

<span class="color-keyword">L</span> 마우스 커서가 위치한 Mesh에 연결된 모든 요소를 선택하는 기능




# 📌 E-xtrude
{: .notice}

<span class="color-comment">Extrude 후 취소해도 Mesh는 복제되어 있음에 주의</span>

<span class="color-keyword">Mesh 선택 → E</span> Mesh를 복제해 돌출 <span class="color-comment">E → S를 이용해서 바깥쪽이나 안쪽으로 돌출할 수 있음</span>

<span class="color-keyword">Face 선택 → Alt + E → Extrude Faces Along Normals</span> 선택한 모든 Face를 하나의 덩어리(연결된 상태)로 유지한 채, 각 Face의 Normal 방향을 고려하여 돌출

<span class="color-variable">Offset Even</span> 돌출 거리를 일정하게 유지할지를 결정

<span class="color-keyword">Face 선택 → Alt + E → Extrude Individual Faces</span> 선택한 각 Face를 완전히 독립적으로 돌출




# 📌 M-erge
{: .notice}

<span class="color-keyword">Vertices 선택 → M</span> 여러 개의 Vertex를 하나로 병합

<span class="color-keyword">→ At Center</span> 선택한 Vertices를 중앙 지점으로 병합 <span class="color-comment">주변 vertices를 이용해 중앙 vertex를 만들기에 좋음, 원형일 때 Extrude로 내부면을 하나 더 뽑아 전부 Merge → At Center</span>

<span class="color-keyword">→ At Cursor</span> 선택한 Vertices를 3D 커서 위치로 병합

<span class="color-keyword">→ At First</span> 첫 번째로 선택한 Vertex 위치로 병합

<span class="color-keyword">→ At Last</span> 마지막으로 선택한 Vertex 위치로 병합 <span class="color-comment">드래그가 아닌 개별 선택해 마지막으로 선택한 Vertex는 하얗게 표시되는데 이렇게 기준이 되는 Mesh를 Active라고 함</span>

<span class="color-keyword">→ By Distance</span> 중복된(겹쳐져 있는) Vertices를 병합, Merge by Distance 패널의 Merge Distance 수치를 조절해 인접한 Vertices를 합칠 수도 있음




# 📌 I-nset
{: .notice}

<span class="color-keyword">Face 선택 → I</span> Face를 복제해 안쪽으로 확장, I를 한 번 더 누를 경우 각 Face를 따로 인셋할지 하나의 큰 Face처럼 인셋할지 토글처럼 사용할 수 있음




# 📌 S-hrink/Fatten
{: .notice}

<span class="color-keyword">Mesh 선택 → Alt + S</span> 선택한 Mesh가 각기 바라보는 방향으로 확장/수축

<span class="color-variable">Offset Even</span> 비율을 유지한 채로 확장/수축




# 📌 K-nife
{: .notice}

<span class="color-keyword">K → Mesh 를 연속해서 LMB → Enter</span> Mesh의 원하는 곳을 연속적으로 클릭해 절단(Edge 생성) <span class="color-comment">Triangle, N-gon 을 Quad 로 만들 때 사용</span>




# 📌 Connect Vertex Path
{: .notice}

<span class="color-keyword">Face 내부의 Vertex 두 개를 선택 → J</span> 선택한 두 Vertex 사이에 Edge를 생성해 Face를 분리하는 기능 <span class="color-comment">Knife를 이용하면 보는 시점에 따라 다르게 잘림, 이 기능을 이용하면 균일하게 자를 수 있음</span>




# 📌 F-ill
{: .notice}

<span class="color-keyword">Vertex 또는 Edge 선택 → F</span> 선택한 Vertex, Edge 사이를 Edge, Face로 채움




# 📌 Bridge Edge Loops
{: .notice}

<span class="color-keyword">마주보는 Edge 선택 → 상단의 Edge 창 → Bridge Edge Loops</span> 마주보는 Edge들을 선택해 사용 시 자동으로 한꺼번에 Fill 됨 <span class="color-comment">아치형(컵 손잡이 등)을 만들 시 떨어지고 비어있는 face의 edge를 선택해 이 기능을 사용 후 패널 창에서 Number of Cuts, Smoothness, Profile Factor, Twist 등을 조절</span>




# 📌 Bridge Faces
{: .notice}

<span class="color-keyword">face와 그 반대편 face 선택 → RMB → Bridge Faces</span> Face 간 구멍을 뚫음




# 📌 Loop Select
{: .notice}

<span class="color-keyword">Alt + Mesh 선택</span> 연속적으로 연결된 Vertex Loop, Edge Loop, Face Loop를 선택




# 📌 Path Select
{: .notice}

<span class="color-keyword">Start Mesh 선택 → End Mesh 를 Ctrl + LMB</span> Loop Select는 쭉 따라서 전부 선택됨, 원하는 곳 까지만 선택하고 싶을 때 이 기능을 사용




# 📌 Edge Slide
{: .notice}

<span class="color-keyword">Vertex 선택 → G → G</span> Edge를 타고 Vertex위치를 조절 할 수 있음, Vertex가 아닌 Edge나 Loop Select에도 사용 가능




# 📌 Loop Cut
{: .notice}

<span class="color-keyword">Ctrl + R</span> Edge Loop를 추가하거나 세분화할 때 사용

<span class="color-comment">- Loop Cut and Slide Panel 을 통해 Number of Cuts, Smoothness 등을 조절</span>

<span class="color-comment">- 노란 선일 때 휠 스크롤을 통해 컷 개수(Number of Cuts)를 정할 수 있음</span>

<span class="color-comment">- 우클릭으로 취소하면 중앙에 생성</span>

<span class="color-comment">- 일정하게 바로 컷 하고 싶다면 Edge, Face 선택 → RMB → Subdivide 을 사용하는 방법도 있음</span>




# 📌 Subdivide
{: .notice}

<span class="color-keyword">Edge, Face 선택 → RMB → Subdivide</span> 선택한 Edge, Face들을 더 잘게 조각내는 기능




# 📌 B-evel
{: .notice}

<span class="color-comment">사용 전에 Apply 창(Ctrl + A)에서 Scale 초기화</span>

<span class="color-keyword">Mesh 선택 → Ctrl + B</span> Vertex, Edge를 깎아 면을 하나 이상 추가해 부드러운 형태로 만드는 기능 <span class="color-comment">Bevel Panel 을 통해 Vertices, Edges 중 적용될 Mesh를 선택하거나 Width, Segments, Shape 등 상세 조절을 할 수 있음</span>
