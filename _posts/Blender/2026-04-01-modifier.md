# 📌 Modifier?
{: .notice}

원본 Mesh를 직접 수정하지 않고 다양한 효과나 변형을 유연하게 적용할 수 있는 기능

여러 개의 Modifier를 사용할 경우 상단에 있는 Modifier부터 우선 적용된다

Modifier는 Apply 하기 전까지 허상이며, Apply 할 경우 수정이 불가능하기 때문에 Apply 전후로 세이브 파일을 따로 생성 <span class="color-comment"> export 시 Apply 필요, 일부 간단한 기능의 Modifier는 다른 중간 수정 작업이 필요할 수 있기 때문에 상황에 따라 Apply </span>




# 📌 Origin?
{: .notice}

일부 Modifier는 Origin을 기준으로 계산, 이 때 Origin은 Modifier가 적용될 기준점, 중심점이 된다

Empty 오브젝트를 만들어 필요한 곳에 위치시켜 Origin으로 사용할 수 있음




# 📌 Modifier 복제
{: .notice}
