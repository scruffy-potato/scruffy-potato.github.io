<span style="color:gray">blender version 5.2.0</span>




# 📌 UV?
{: .notice}

3D Mesh의 표면 위치를 2차원 좌표로 표현하기 위한 좌표계

```
1 ┌───────┐
  │                 │
V│                 │
  │                 │
0 └───────┘
  0        U        1
```




# 📌 2D Texture
{: .notice}

2차원 평면상의 이미지 또는 데이터를 이용하여 3D 객체의 표면 정보를 표현하는 텍스처




# 📌 Textureing
{: .notice}

3D Mesh의 표면에 Texture를 적용하여 색상, 표면의 질감 및 기타 표면 특성을 표현하는 작업 또는 과정




# 📌 UV Mapping
{: .notice}

3D Mesh의 표면과 2D Texture의 좌표를 대응시키는 과정 또는 그 관계




# 📌 UV Island
{: .notice}

Seam에 의해 분리되어 펼쳐진 각각의 덩어리

<span class="color-keyword">4</span>UV Island Selection Toggle




# 📌 Live Unwrap
{: .notice}

<span class="color-keyword">Viewport 우측 상단 Symmetry 우측의 Options → UVs → Live Unwrap</span> Mark, Clear Seam 사용 시 실시간으로 UV Editor에 적용




# 📌 Export
{: .notice}

<span class="color-keyword">UV Editor 상단의 UV → Export UV Layout</span>

<span class="color-comment">All UVs 체크 시 UV Layout 안의 모든 UV 추출, 체크 안 할 시 선택된 UV만 추출</span>

<span class="color-comment">기본적인 사이즈는 1024*1024</span>

<span class="color-comment">Export 전에 UV들이 0이나 1(경계선)에 닿지 않게 이동</span>




# 📌 Seam
{: .notice}

UV Unwrapping 시 3D Mesh를 어디에서 잘라서 2D로 펼칠지 지정하는 Edge, 절단선

<span class="color-keyword">Edge 선택 → RMB → Mark Seam</span>

<span class="color-keyword">Edge 선택 → RMB → Clear Seam</span>




# 📌 Unwrap
{: .notice}

<span class="color-keyword">Face Select Mode에서 → A → U(UV Unwrap Faces) → Project from View 또는 Project from View(Bounds)</span>

<span class="color-keyword">UV Editor에서 → A → Unwrap</span>




# 📌 Stitch, Split
{: .notice}

<span class="color-keyword">붙일 UV Edge 선택 → Stitch</span>

<span class="color-keyword">분리할 UV Face 선택 → Split → Selection</span>




# 📌 기본적인 Seam 형태
{: .notice}

Seam은 기본적으로 정면이 아닌 뒤쪽, 안 보이는 쪽에 생성

<span class="color-keyword">Sphere</span> 뒤쪽 중앙부터 ¼π 십자로 자르기

<span class="color-keyword">Cylinder</span> 통조림을 생각하며 뚜껑, 바닥을 자르고 뒤쪽으로 가로지르는 선으로 자르기

<span class="color-keyword">Cube</span> 주사위 도면을 생각하며 자르기
