# 📌 Object, Edit Mode 간 전환
{: .notice}

• <span class="color-keyword">Tab</span>




# 📌 Edit Mode 에서 Object 로 분리
{: .notice}

• <span class="color-keyword">메시를 오브젝트로 분리</span> : 분리 할 Mesh 선택 → P → Selection




# 📌 Vertex, Edge, Face
{: .notice}

• <span class="color-keyword">Vertex</span> : 1

• <span class="color-keyword">Edge</span> : 2

• <span class="color-keyword">Face</span> : 3




# 📌 Transform Pivot Point
{: .notice}

<img src="/img/Blender/transform-pivot-point.png"/>

• <span class="color-keyword">Bounding Box Center</span> : 선택된 오브젝트의 외곽을 감싸는 최소한의 박스의 중심이 Pivot이 됨

• <span class="color-keyword">3D Cursor</span> : 현재 3D Cursor가 Pivot이 됨

• <span class="color-keyword">Individual Origins</span> : Origin이 Pivot이 됨, 여러 오브젝트를 선택할 때 각각의 오브젝트가 자기 자신의 Origin을 Pivot으로 가짐

• <span class="color-keyword">Median Point</span> : 여러 오브젝트를 선택할 때 오브젝트들의 Origin의 중앙점이 Pivot이 됨

• <span class="color-keyword">Active Element</span> : 여러 오브젝트를 선택할 때 Active(마지막으로 선택된) 오브젝트의 Origin이 Pivot이 됨




# 📌 E-xtrude
{: .notice}

• <span class="color-keyword">Mesh 선택 → E</span> : Mesh 를 복제해 확장 <span class="color-comment">Extrude 후 취소해도 Mesh 는 복제되어 있음에 주의</span>




# 📌 M-erge
{: .notice}

• <span class="color-keyword">Vertices 선택 → M</span> : 여러 개의 Vertex를 하나로 병합

• <span class="color-keyword">→ At Center</span> : 선택한 Vertices를 중앙 지점으로 병합

• <span class="color-keyword">→ At Cursor</span> : 선택한 Vertices를 3D 커서 위치로 병합

• <span class="color-keyword">→ At First</span> : 첫 번째로 선택한 Vertex 위치로 병합

• <span class="color-keyword">→ At Last</span> : 마지막으로 선택한 Vertex 위치로 병합

• <span class="color-keyword">→ By Distance</span> : 중복된(겹쳐져 있는) Vertices를 병합




# 📌 I-nset
{: .notice}

• <span class="color-keyword">Face 선택 → I</span> : Face를 복제해 안쪽으로 확장




# 📌 F-ill
{: .notice}

• <span class="color-keyword">Vertex 또는 Edge 선택 → F</span> : 선택한 Vertex, Edge 사이를 Edge, Face로 채움




# 📌 B-evel
{: .notice}

<span class="color-comment">사용 전에 Apply 창(Ctrl + A)에서 Scale 초기화</span>

• <span class="color-keyword">Mesh 선택 → Ctrl + B</span> : Vertex, Edge의 모서리를 둥글게 깎아 부드러운 형태로 만듦 <span class="color-comment">(Bevel Panel 을 통해 Vertices, Edges 중 적용될 Mesh를 선택하거나 Width, Segments, Shape 등 상세 조절을 할 수 있음)</span>




# 📌 Loop Cut
{: .notice}

• <span class="color-keyword">Ctrl + R</span> : 엣지 루프를 추가하거나 세분화할 때 사용 <span class="color-comment">Loop Cut and Slide Panel 을 통해 Number of Cuts, Smoothness 등을 조절</span>

<span class="color-comment">노란 선일 때 휠 스크롤을 통해 컷 개수(Number of Cuts)를 정할 수 있음</span>

<span class="color-comment">우클릭으로 취소하면 중앙에 생성</span>

<span class="color-comment">일정하게 바로 컷 하고 싶다면 Edge, Face 선택 → RMB → Subdivide 을 사용하는 방법도 있음</span>





# 📌 Loop Select
{: .notice}

• <span class="color-keyword">Alt + Mesh 선택</span> : 연속적으로 연결된 Vertex Loop, Edge Loop, Face Loop를 선택
