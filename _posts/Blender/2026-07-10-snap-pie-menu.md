# 📌 Snap Pie Menu
{: .notice}

• <span class="color-keyword">Shift + S</span> : 커서 위치에 Snap Pie Menu 팝업 창 생성

 ◦ <span class="color-variable">Cursor to World Origin</span> : 3D Cursor를 월드 원점(0, 0, 0)으로 위치

 ◦ <span class="color-variable">Cursor to Selected</span> : 3D Cursor를 선택한 요소의 중앙에 위치

 ◦ <span class="color-variable">Cursor to Active</span> : 3D Cursor를 Active 요소의 중앙에 위치

 ◦ <span class="color-variable">Cursor to Grid</span>

 ◦ <span class="color-variable">Selection to Grid</span>

 ◦ <span class="color-variable">Selection to Cursor (Keep Offset)</span> : 선택한 요소들 사이의 상대적인 거리를 유지한 채 3D Cursor 위치로 이동
 
 ◦ <span class="color-variable">Selection to Cursor</span> : 선택한 요소를 3D Cursor 위치로 이동

 ◦ <span class="color-variable">Selection to Active</span> : 선택한 요소를 Active 요소의 위치로 이동
