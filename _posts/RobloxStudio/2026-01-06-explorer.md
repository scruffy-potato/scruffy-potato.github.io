# 📌 Workspace
{: .notice}

3D World Space를 구성하고 물리 엔진의 영향을 받는 객체들을 담는 컨테이너




# 📌 Players
{: .notice}

현재 게임에 들어와 있는 Player들을 관리




# 📌 Lighting
{: .notice}

3D World Space의 전체적인 빛, 시간대, 색 보정, 환경 효과를 관리




# 📌 MaterialService
{: .notice}

로블록스의 기본 Material을 포함해 Custom Material을 관리




# 📌 NetworkClient
{: .notice}

Roblox 내부 네트워크 시스템으로, 플레이어의 게임 클라이언트가 Roblox 서버와 연결되어 통신하는 장치




# 📌 ReplicatedFirst
{: .notice}

게임이 시작될 때 클라이언트에게 가장 먼저 복제되어야 하는 객체를 넣어두는 곳(로딩 화면, 초기화 LocalScript, 게임 시작 연출)




# 📌 ReplicatedStorage
{: .notice}

서버와 클라이언트 양쪽에서 접근할 수 있는 공용 저장 공간




# 📌 ServerScriptService
{: .notice}

서버에서 실행되어야 하는 Script를 보관하는 곳




# 📌 ServerStorage
{: .notice}

서버에서만 접근할 수 있는 객체를 보관하는 곳




# 📌 StarterGui
{: .notice}

게임에 들어온 플레이어에게 보여줄 GUI의 원본을 넣어두는 곳




# 📌 StarterPack
{: .notice}

게임에 들어온 플레이어가 기본적으로 지급받는 Tool을 넣어두는 곳




# 📌 StarterPlayer
{: .notice}

캐릭터와 플레이어의 기본 설정을 관리하는 곳

<span class="color-keyword">StarterCharacterScripts</span> 캐릭터가 생성, 재생성될 때 캐릭터에 복제되는 Script를 넣는 곳(달리기, 움직임, 애니메이션, 발자국 등)

<span class="color-keyword">StarterPlayerScripts</span> 플레이어에게 복제되는 플레이어 전용 LocalScript를 넣는 곳(카메라, Input, 게임 UI와 관련된 클라이언트 처리 등)




# 📌 Teams
{: .notice}

플레이어를 여러 개의 팀으로 나누고 각 팀의 이름, 색상, 소속 플레이어 등을 관리하는 곳




# 📌 SoundService
{: .notice}

게임 전체의 오디오 환경을 관리, BGM같은 2D Sound를 두는 공간으로도 사용




# 📌 TextChatService
{: .notice}

Roblox의 게임 내 텍스트 채팅 시스템을 관리
