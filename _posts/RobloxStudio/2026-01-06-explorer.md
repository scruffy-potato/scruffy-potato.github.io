# 📌 Workspace
{: .notice}

게임의 3D 세계를 관리하는 공간(World Space의 오브젝트 들)




# 📌 Players
{: .notice}

현재 게임에 들어와 있는 플레이어를 관리




# 📌 Lighting
{: .notice}

게임의 조명과 환경을 관리




# 📌 MaterialService
{: .notice}

게임에서 사용하는 Material을 관리




# 📌 NetworkClient
{: .notice}

Roblox 내부 네트워크 시스템




# 📌 ReplicatedFirst
{: .notice}

게임이 시작될 때 클라이언트에게 가장 먼저 복제되는 영역(로딩 화면, 초기화 LocalScript, 게임 시작 연출)




# 📌 ReplicatedStorage
{: .notice}

서버와 클라이언트 양쪽에서 접근할 수 있는 공용 저장 공간




# 📌 ServerScriptService
{: .notice}

서버에서 실행되는 Script를 넣는 곳




# 📌 ServerStorage
{: .notice}

서버만 접근할 수 있는 저장 공간




# 📌 StarterGui
{: .notice}

플레이어에게 지급할 GUI의 원본을 넣는 곳




# 📌 StarterPack
{: .notice}

플레이어가 게임을 시작할 때 지급받는 Tool의 원본을 넣는 곳




# 📌 StarterPlayer
{: .notice}

플레이어와 플레이어 캐릭터의 기본 설정 및 Script를 관리

<span class="color-keyword">StarterCharacterScripts</span> 캐릭터가 생성될 때 캐릭터에 복사되는 Script를 넣는 곳(달리기, 움직임, 애니메이션, 캐릭터 관련 기능 등)

<span class="color-keyword">StarterPlayerScripts</span> 플레이어에게 복사되는 플레이어 전용 LocalScript를 넣는 곳(카메라, Input, 클라이언트 시스템 등)




# 📌 Teams
{: .notice}

플레이어를 팀으로 나누는 시스템




# 📌 SoundService
{: .notice}

게임의 전반적인 사운드 시스템을 관리




# 📌 TextChatService
{: .notice}

Roblox의 텍스트 채팅 시스템을 관리
