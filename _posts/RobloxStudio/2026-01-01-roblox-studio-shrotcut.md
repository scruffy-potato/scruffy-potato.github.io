# 📌 유연한 작업
{: .notice}

<span class="color-keyword">F5</span> Play

<span class="color-keyword">Shift + F5</span> Stop Play

<span class="color-keyword">Detele, Backspace</span> 선택한 파트 제거




# 📌 카메라 컨트롤
{: .notice}

<span class="color-keyword">WASD</span> 카메라 앞뒤좌우 이동

<span class="color-keyword">MMB Holding-Down</span> 카메라 상하좌우 이동

<span class="color-keyword">Wheel Up, Down</span> 커서 방향으로 줌 인/아웃

<span class="color-keyword">RMB Holding-Down</span> 카메라 회전

<span class="color-keyword">F</span> Zoom to 선택한 파트




# 📌 선택 도구
{: .notice}

<span class="color-keyword">1</span> Select

<span class="color-keyword">2</span> Move

<span class="color-keyword">3</span> Scale

<span class="color-keyword">4</span> Rotate

<span class="color-keyword">5</span> Transform
