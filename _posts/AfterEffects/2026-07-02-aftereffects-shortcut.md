# 📌 프로젝트 제어
{: .notice}

• <span class="color-keyword">Ctrl + N</span> : 새 컴포지션 생성

• <span class="color-keyword">Ctrl + Alt + N</span> : 새 프로젝트 생성

• <span class="color-keyword">Ctrl + K</span> : 컴포지션 세팅

• <span class="color-keyword">Ctrl + Alt + Shift + S</span> : 증분 저장

• <span class="color-keyword">Ctrl + Z</span> : Undo

• <span class="color-keyword">Ctrl + Shift + Z</span> : Redo




# 📌 타임라인
{: .notice}

• <span class="color-keyword">Space</span> : 프리뷰 재생/정지

• <span class="color-keyword">Home, End</span> : 첫, 마지막 프레임으로 이동

• <span class="color-keyword">Ctrl + 방향키 좌, 우</span> : 이전, 다음 프레임으로 이동, Shift 키도 홀드 시 10 프레임 단위로 이동

• <span class="color-keyword">B, N</span> : 워크에어리어 시작점, 종료점 설정

• <span class="color-keyword">J, K</span> : 이전, 다음 키 프레임으로 이동

• <span class="color-keyword">키 프레임 선택 → Alt + 방향키 좌, 우</span> : 키 프레임을 이전, 다음 프레임으로 이동, Shift 키도 홀드 시 10 프레임 단위로 이동

• <span class="color-keyword">F9</span> : Easy Ease

• <span class="color-keyword">Shift + F9</span> : Easy Ease In(감속 생성)

• <span class="color-keyword">Ctrl + Shift + F9</span> : Easy Ease Out(가속 생성)

• <span class="color-keyword">키 프레임을 Ctrl + LMB</span> : Easy Ease 해제

• <span class="color-keyword">그래프 에디터에서 키 프레임을 Alt + LMB</span> : Easy Ease 해제

• <span class="color-keyword">G</span> : 그래프 에디터에서 키 포인트를 추가/제거




# 📌 프리뷰
{: .notice}

• <span class="color-keyword">V</span> : 선택/이동 도구

• <span class="color-keyword">H</span> : 화면 이동, 스페이스 바 + 드래그로도 가능

• <span class="color-keyword">Z</span> : 화면 확대 도구, 이 상태에서 Alt 키 홀드 중 축소 도구로 변경됨

• <span class="color-keyword">Y</span> : 선택한 소스의 앵커 포인트를 드래그해 이동할 수 있음, Ctrl 키 홀드 중 드래그 시 Snap 적용

• <span class="color-keyword">Ctrl + Alt + Home</span> : 선택한 소스의 앵커 포인트를 소스의 중심으로 이동

• <span class="color-keyword">W</span> : 소스 회전 도구

• <span class="color-keyword">G</span> : 펜 도구




# 📌 레이어
{: .notice}

• <span class="color-keyword">Ctrl + D</span> : 레이어 복제

• <span class="color-keyword">Ctrl + Shift + D</span> : 타임라인의 인디케이터를 기준으로 양쪽으로 나누어 레이어 분할

• <span class="color-keyword">Alt + [, ]</span> : 타임라인의 인디케이터 기준 In, Out 자르기

• <span class="color-keyword">I, O</span> : 타임라인의 인디케이터를 선택한 레이어의 In, Out으로 이동

• <span class="color-keyword">Alt + Page Up/Down</span> : 레이어 In, Out의 프레임 이동, Shift 키도 홀드 시 10프레임 단위로 이동

• <span class="color-keyword">Ctrl + Home</span> : 레이어의 앵커 포인트를 뷰 중앙 정렬, 앵커 포인트에 맞게 포지션도 이동

• <span class="color-keyword">P, R, S</span> : Position, Rotation, Scale 속성만 표시

• <span class="color-keyword">T</span> : Opacity 속성만 표시

• <span class="color-keyword">A</span> : Anchor Point 속성만 표시

• <span class="color-keyword">E</span> : Effects 그룹만 표시

• <span class="color-keyword">U</span> : 키 프레임이 존재하는 속성만 표시

• <span class="color-keyword">Ctrl + Y</span> : 전체를 채우는 솔리드 레이어 생성(배경), Ctrl + Shift + Y로 생성된 솔리드 수정
